# 08 — 临期约束接入策略选择

**What to build:** 距到期 ≤3 天时，策略选择自动排除「新开当月单腿」，改推次月单腿或观望，并说明当月合约为什么被排除——让你理解这是纪律而不是功能缺失。

**Blocked by:** 05 — 到期日历；07 — 策略选择引擎核心

**Status:** ready-for-agent

- [ ] 距到期 ≤3 天时，策略类型不再产出「新开当月单腿」
- [ ] 此时优先给出次月单腿（或垂直价差）作为替代
- [ ] 无法给出替代时（如次月流动性不足）明确建议观望
- [ ] 输出包含「当月合约被排除」的说明，含剩余天数
- [ ] 距到期 >3 天时不受此约束，策略类型与 07 一致
- [ ] 约束只影响「新开仓」的当月建议，不影响到期日历与临期提醒本身
- [ ] 约束判定并入策略判定纯函数，有单元测试覆盖恰好 3 天、恰好 4 天、替代不可用三种情形
- [ ] 前端决策卡展示排除说明并通过构建
