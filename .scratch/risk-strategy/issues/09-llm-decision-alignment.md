# 09 — 大模型决策层整合

**What to build:** 大模型给出的方案与规则层结论一致，不再出现「建议观望却给了买单」这类矛盾。决策的动作枚举能表达垂直价差（含两条腿的合约标识），提示中带上策略类型、临期约束与手数上限。

**Blocked by:** 02 — 手数上限与单张最大亏损；07 — 策略选择引擎核心；08 — 临期约束接入策略选择

**Status:** ready-for-agent

- [ ] 决策动作枚举可表达垂直价差，并能携带两条腿的合约标识
- [ ] 提示中注入策略类型、策略理由、临期约束与手数上限
- [ ] 规则层给出「观望」时，模型输出不得给出买入动作
- [ ] 模型给出的动作与规则层策略类型一致；不一致时以规则层为准且有可观察的落点
- [ ] 模型给出的建议张数不超过手数上限
- [ ] 现有决策字段（方向、入场、止损、止盈、置信度、持有窗口、理由、风险）保持兼容
- [ ] 大模型不可用或返回非法 JSON 时降级，不抛 500
- [ ] 响应解析与一致性校验为可测形态，有测试覆盖「规则层观望但模型给买单」等冲突用例
- [ ] 前端决策卡能展示价差的两条腿并通过构建
