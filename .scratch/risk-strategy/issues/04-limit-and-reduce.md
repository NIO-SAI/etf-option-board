# 04 — 限额对比与减仓建议

**What to build:** 敞口旁边显示限额，并给出纪律动作。限额以「标的金额当量（元）」为主显示、占总资金比例为副，元值由总资金与风险偏好档推导（风险偏好档与单笔风险%联动：1%→保守 / 2%→标准 / 3%→激进）。敞口触限时给出**可执行**的减仓建议——「减到 N 张」，而不是只报一串数字。

**Blocked by:** 02 — 手数上限与单张最大亏损；03 — 敞口档位与组合 Greeks 敞口

**Status:** ready-for-agent

- [ ] 限额以元为主、占总资金比例为副地展示
- [ ] 限额元值由总资金与风险偏好档推导，风险偏好档与单笔风险%联动
- [ ] 敞口与限额可直接对比，能看出还剩多少空间
- [ ] 触限时给出减仓建议，且建议是可执行的张数（「减到 N 张」）
- [ ] 敞口恰好等于限额时的触限判定明确且一致
- [ ] 未触限时不出现多余的减仓提示
- [ ] 设置缺失或敞口缺失时限额区块降级提示，不抛 500
- [ ] 触限判定与减仓张数计算为纯函数，有单元测试覆盖临界值
- [ ] 前端展示限额对比与建议并通过构建
