# 策略选择引擎只覆盖买方策略

策略选择引擎的输出限定为四类：**买单腿认购 / 买单腿认沽 / 垂直价差 / 观望**，明确排除备兑开仓、保护性认沽、铁鹰与跨式。

理由是看板的定位是「日内方向决策」：铁鹰 / 跨式属于不预测方向的收租策略，与定位冲突；且已决定不做多腿盈亏引擎，推荐了也无法展示其风险（最大亏损、保证金占用）。备兑在 A 股有保证金优惠、确有价值，但需要「持有ETF」档位的**精确份额**才能给出备兑比例，与 ADR-0001 的档位近似模型不匹配。

## Considered Options

- **五类（含备兑开仓与保护性认沽）**：与「持有ETF」档位天然咬合（持ETF + 高IV看多 → 备兑），但备兑比例需要精确份额，档位近似给不出。
- **完整集合（再加铁鹰 / 跨式宽跨 / 卖出认沽）**：覆盖震荡收租，但与看板定位冲突，且在无多腿盈亏引擎时无法展示风险。
- **仅买方四类（本决定）**。

## Consequences

- 「持有ETF」档位只服务组合 Greeks 纪律，不参与策略建议。
- 高 IV + 看多时改推牛市看涨价差以降低成本；高 IV + 震荡时只能「观望」，不能收租。
- `services/llm.py` 的 `action` 枚举需同步扩展以容纳价差（现仅 `buy_call | buy_put | wait`）。
