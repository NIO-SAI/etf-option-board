# 09 — 概念资金分时页对齐 stock-webui /board-flow 交互

**Status:** done

复刻 stock-webui `/board-flow` 的列表 + 叠加曲线交互（用户反馈「差别太大」）。

## 已实现（对齐项）

- 左侧列表：搜索框（名称/代码）、排序（涨幅 / 资金，点击同键切换升/降序）、
  批量按钮（流入Top10 / 流出Top10 / 全选 / 清空 / 反选）；
- 每行：勾选框 + 名称 + 涨跌幅 + 主力净流入 + 自定义按钮（`+` 加入 / `✓` 移除，实时生效）；
- 五个口径 Tab：概念 / 行业 / **指数** / 热门 / 自定义；
- 右侧多条线叠加：勾选几个就画几条，线末 endLabel 显示「名称 + 资金 + 涨跌幅」；
- 悬停左侧**未勾选**的板块 → 图上临时画一条**橙色虚线**（不改变勾选）；悬停已勾选的板块 → 该线加粗、
  其余线变淡；移开即恢复；
- 默认勾选与 stock-webui 一致：概念/行业 = 流入 Top10 + 流出末 5；指数/热门/自定义 = 全选；
  选择按口径记忆（localStorage），跨刷新保留；
- 右上工具：日期回看（库内有数据的交易日）、今日、刷新（同时清空分时缓存重拉）、最后更新时间、历史角标；
- 分时数据按 90 秒 TTL 缓存，分块（60 个/批）拉取，命中缓存时不发请求；
- 双击行打开详情抽屉（stock-webui 在「全景」里看深度剖析，这里用抽屉替代，不影响主交互）。

## 未复刻（有明确原因）

- **涨速排序**：stock-webui 的涨速来自其采集器的额外字段，本项目排行接口没有该数据；
- **全景 Tab（treemap + 深度剖析）**：属于另一套可视化，本次聚焦分时页主流程，未包含。

- 新增 `/api/board/index-rank`：指数 / 全 A 排行（来自 `em_flow_points` 最新一刻），供「指数」Tab 使用。
