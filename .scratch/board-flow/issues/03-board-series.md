# 03 — 板块当日分时曲线 + 历史日期回看

**What to build:** 「概念资金分时」页展示排行前 N 个板块的当日主力资金分时曲线（多线、图例、悬停取数），
点表头排序变化时曲线随所选板块更新；可切换到历史日期查看当日的排行与分时。曲线由本地库的分钟点拼接，
接口按时间轴对齐（前值填充 + 同日校验），与前端口径一致；数据缺失的日子给出明确空态而不是断线。

**Blocked by:** 02 — 板块排行端到端。

**Status:** ready-for-agent

- [ ] 排行列表与分时曲线同屏；切换排序/标签时曲线跟随，切换本身不发多余请求（缓存命中）
- [ ] 曲线带图线开关（常驻，无数据时置灰），开关不引起布局跳动
- [ ] 历史日期回看：可列出最近可回看的日期，选中后排行与曲线同时切换到该日
- [ ] 当日无分时数据（如服务中途启动）时显示「自启动起累积」的提示，不谎报缺失
- [ ] 序列对齐纯函数单测：错位时间点、缺失分钟、跨午夜/同日校验
- [ ] 非交易时段轮询降频，页面隐藏时停止请求
