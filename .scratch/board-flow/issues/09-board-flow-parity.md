# 09 — 概念资金分时页对齐 stock-webui /board-flow 交互

**Status:** done

复刻 stock-webui `/board-flow` 的列表 + 叠加曲线交互（用户反馈「差别太大」）。

## 已实现（对齐项）

- 左侧列表：搜索框（名称/代码）、排序（涨幅 / 资金，点击同键切换升/降序）、
  批量按钮（流入Top10 / 流出Top10 / 全选 / 清空 / 反选）；
- 每行：勾选框 + 名称 + 涨跌幅 + 主力净流入 + 自定义按钮（`+` 加入 / `✓` 移除，实时生效）；
- 五个口径 Tab：概念 / 行业 / **指数** / 热门 / 自定义；
- 右侧多条线叠加：勾选几个就画几条，线末 endLabel 显示「名称 + 资金 + 涨跌幅」；
- 悬停左侧**未勾选**的板块 → 图上临时画一条**橙色虚线**（不改变勾选）；悬停已勾选的板块 → 该线加粗、
  其余线变淡；移开即恢复；
- 默认勾选与 stock-webui 一致：概念/行业 = 流入 Top10 + 流出末 5；指数/热门/自定义 = 全选；
  选择按口径记忆（localStorage），跨刷新保留；
- 右上工具：日期回看（库内有数据的交易日）、今日、刷新（同时清空分时缓存重拉）、最后更新时间、历史角标；
- 分时数据按 90 秒 TTL 缓存，分块（60 个/批）拉取，命中缓存时不发请求；
- 双击行打开详情抽屉（stock-webui 在「全景」里看深度剖析，这里用抽屉替代，不影响主交互）。

## 未复刻（有明确原因）

- **涨速排序**：stock-webui 的涨速来自其采集器的额外字段，本项目排行接口没有该数据；
- **全景 Tab（treemap + 深度剖析）**：属于另一套可视化，本次聚焦分时页主流程，未包含。

## 后端配套

- `/api/board/series` 现在返回 `final_flow` / `pct`，并支持指数代码（用 4 维表的「机构 + 大单」合成主力净流入）；
- 新增 `/api/board/index-rank`：指数 / 全 A 排行（来自 `em_flow_points` 最新一刻），供「指数」Tab 使用。

## 追加修复（用户反馈：排序缺涨幅 / 自定义按钮不变化 / 图标不明显）

浏览器复现（red）：
1. 点行尾 `+` 后按钮仍是 `+`，但 `GET /api/board/watch` 已包含该板块 —— 属**前端未刷新**，
   用户观感就是「没添加进去」；
2. 自定义按钮是 10px 文字 `+`，在深色列表里几乎看不见；
3. 排序只有一个看起来像文字的 `资金↓`，`涨幅` 按钮存在但无边框/无箭头，辨识度低。

修复（green）：
- 自选改为**乐观更新**：状态从 `watchView` 同步到本地 `watchItems`，点击 `+` 立即变 `✓`、
  「自定义」Tab 立即出现该板块；请求失败自动回滚并 toast；成功后后台 `refreshWatch()` 与服务端对齐；
- 自选按钮改为 20×20 的带边框图标按钮（`Plus` / `Check`，加载中显示 spinner），
  已加入时用 warning 底色，未加入时 hover 变主色，`aria-pressed` 标注状态；
- 排序改为带边框的分段控件：`涨幅` / `资金` 常驻可见，激活项主色填充并显示 `↓/↑`，
  再点同一项切换升降序；
- 每次增删按代码加 busy 锁，避免连点导致重复请求。

浏览器验证（green）：
- 点 `涨幅` → `aria-pressed=true`、箭头 `↓`、首行变为 `+11.53%` 的高带宽内存；
- 点某行 `+` → 按钮立刻变 `✓`（`aria-label=移除自定义`, `aria-pressed=true`），
  `GET /api/board/watch` 新增 `BK1152`，「自定义」Tab 立即出现「高带宽内存」；
- 在「自定义」点 `✓` → 行立即消失、`/api/board/watch` 同步移除；
- 按钮实测 20×20、有边框与图标（lucide `check`），排序分组含 2 个按钮。
