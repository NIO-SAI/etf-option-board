# 05 — 主力资金多日图

**What to build:** 「主力资金多日图」页：选起止日期后展示区间累计资金流入的板块排行，并可勾选多个板块看
区间资金流走势对比（单板块时看自身节奏）。一页一次请求拿到排行与 Top N 序列，切换日期区间时先渲染缓存再刷新。

**Blocked by:** 02 — 板块排行端到端。

**Status:** done

- [x] 默认区间为最近 5 个交易日，可改；超出库覆盖范围时明确提示
- [x] 区间累计排行与走势图联动，勾选的板块顺序稳定、颜色固定
- [x] 单板块视图与多板块视图切换不重新请求
- [x] 区间内某日无数据不产生断崖假象（缺口按缺失处理并标注）
- [x] 缓存键包含起止日期，重复进入同一区间零请求
- [x] 排行/序列的区间汇总计算为纯函数并有单测（含空区间、单日区间）
