# 所有可点击元素鼠标悬停显示「小手」

> *This was generated by AI during triage.*

**Category:** enhancement
**Status:** ready-for-agent
**Source:** 用户反馈 #4

## 现状

全站只有实时告警列表的整行点击显式写了 `cursor-pointer`。ETF 列表行、合约行、左侧指数行、图表切换、卡片标题上的按钮、可点击的徽标/链接等大量交互目标，鼠标悬停仍是默认箭头，用户无法预判哪里能点。

## 期望

- 所有**可点击**元素悬停时 `cursor: pointer`。
- 不可用的交互目标用 `cursor: default` 或 `not-allowed`，不要出现「看着能点却没反应」。
- 纯展示元素（文本、数值、图表画布空白处）保持默认箭头。

## 实施提示

- 优先在共享组件（Button、表格行、列表项、Card 可点击态）统一加，而不是逐个业务点打补丁。
- 表格里「整行可点击」时给 `<tr>` 加 `cursor-pointer`；行内有独立按钮时按钮自己也要有。
- ECharts 图表本身若绑定了点击（如点击 legend/标记），用 `cursor: pointer` 或 ECharts 的 `cursor` 配置。

## 验收

- [ ] 逐一点击区域巡检：ETF 列表行、指数行、合约列表行、筛选/切换按钮、告警整行、可点击徽标、图表可点击标记，悬停均显示小手
- [ ] 禁用的按钮悬停不显示小手
- [ ] 纯文本/数值区域悬停仍是默认箭头
- [ ] 浏览器里用 `getComputedStyle(el).cursor` 抽查，值为 `pointer`
- [ ] 移动端无视觉回归

## 不在范围

- 不改点击行为，只改光标反馈
- 不重做按钮/行组件的视觉样式
