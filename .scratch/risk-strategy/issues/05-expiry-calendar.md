# 05 — 到期日历

**What to build:** 一个到期日历，列出四个合约月份的到期日与倒计时：当月、下月、随后两个季月。到期日按「到期月第 4 个星期三」计算，跨年（如 12 月看次年）也正确。纯计算，不依赖任何设置，也不引入新数据源。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 列出四个合约月份（当月、下月、随后两个季月）及其到期日
- [ ] 到期日按到期月第 4 个星期三计算
- [ ] 展示距到期天数（自然日口径）
- [ ] 跨年场景正确（年末时次年月份的到期日不早于当日、年份取对）
- [ ] 当月已过第 4 个星期三时，合约月份推进规则明确且一致
- [ ] 通过端点暴露，失败时返回 `{error}` 不抛 500
- [ ] 到期日与距到期计算为纯函数，当日日期由调用方注入，不读系统时钟
- [ ] 有单元测试覆盖第 4 个星期三、跨年、月份推进、距到期天数
- [ ] 前端展示到期日历区块并通过构建
