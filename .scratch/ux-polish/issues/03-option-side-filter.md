# 合约列表支持筛选：全部 / 仅认购 / 仅认沽

> *This was generated by AI during triage.*

**Category:** enhancement
**Status:** ready-for-agent
**Source:** 用户反馈 #10

## 现状

合约列表（候选合约区）把认购和认沽混在一起按评分排序，无法只看一方。做单边行情时，另一半会持续占据视线和滚动空间。

## 期望

- 列表上方加分段筛选：**全部 / 认购 / 认沽**，默认「全部」。
- 切换即时生效，不重新请求数据（本地过滤）。
- 显示各档数量，例如「全部 24 · 认购 12 · 认沽 12」。
- 选中态清晰（语义色沿用现有 Badge/分段控件规范；认购用现有的 up/红系，认沽用 down/绿系，仅作小标识，不整片染色）。
- 筛选状态不需要持久化（默认每次打开为「全部」）。

## 边界情况

- 某一侧为空时，切过去显示空态「当前无认购合约」，不要整块消失或报错。
- 已选中某合约后切到不含它的档位：主图保持该合约不变，列表只是不显示它；再次点「全部」恢复。
- 与现有「按评分排序」「最优合约高亮」逻辑叠加，不改变排序规则。

## 验收

- [ ] 三个档位可切换，默认「全部」
- [ ] 「仅认购」只显示 `type === "call"`，反之亦然
- [ ] 各档数量正确，并与筛选结果条数一致
- [ ] 切换不触发网络请求（Network 面板无新请求）
- [ ] 空档位有明确空态文案
- [ ] 选中合约不被筛选意外清空
- [ ] 键盘可操作，选中态有 aria-pressed 或等价语义

## 不在范围

- 不按行权价/到期日/虚值实值筛选
- 不记住用户上次筛选
