# 02 — 手数上限与单张最大亏损

**What to build:** 决策卡上出现「最多 N 张」——由单笔风险预算除以单张最大亏损、向下取整得出，并说明这个最大亏损是怎么算出来的。买单腿与垂直价差两种口径都要算准。当风险预算不足以开 1 张时，明确告诉你「按当前风险预算不应开仓」，而不是显示「最多 0 张」。

**Blocked by:** 01 — 设置：总资金与单笔风险%（含测试缝骨架）

**Status:** ready-for-agent

- [ ] 决策输出中给出单笔风险预算（总资金 × 单笔风险%）
- [ ] 给出「最多 N 张」，N 为向下取整的整数
- [ ] 单张最大亏损：买单腿按权利金全额；垂直价差按行权价宽度减净收
- [ ] 界面展示单张最大亏损的构成，便于自己核对
- [ ] N 算得 0 时展示「按当前风险预算不应开仓」的明确文案，而非「最多 0 张」
- [ ] 风险预算恰好整除单张最大亏损时，边界取整正确
- [ ] 单张最大亏损为 0 或缺失时降级提示，不除以零、不抛 500
- [ ] 手数上限计算为纯函数，有单元测试覆盖取整、整除边界、结果为 0
- [ ] 前端决策卡显示该字段并通过构建
