# 04 — 板块详情抽屉（六块一次拿全）

**What to build:** 点任一板块，从右侧滑出详情抽屉，一次请求拿全六块内容并各自独立渲染/降级：
当日累计净流入曲线 + 每分钟增量柱、板块成分股资金排行、近 20 个交易日资金历史、与对标指数的资金走势对比、
研报/资讯热度。抽屉不遮挡列表、可关闭回到原滚动位置，切板块不丢上下文。

**Blocked by:** 03 — 板块当日分时曲线 + 历史日期回看。

**Status:** ready-for-agent

- [ ] 抽屉一次请求完成加载；任一子块失败只让该块显示空态，其余照常
- [ ] 抽屉内可切换日期（与页面日期选择一致）
- [ ] 成分股排行可点个股跳转（或至少展示名称/资金/涨幅，非空）
- [ ] 近 20 日历史曲线在库中数据不足时如实标注覆盖区间
- [ ] 对比指数曲线与板块曲线共用同一条时间轴（不错位）
- [ ] 抽屉打开/关闭有动画但不造成图表 resize 抖动
- [ ] 详情数据进 IndexedDB 缓存，重复打开同一板块当日不再请求
