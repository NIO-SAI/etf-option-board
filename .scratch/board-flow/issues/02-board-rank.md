# 02 — 板块排行端到端：采集器落库 → 排行接口 → 概念/行业/自选排行页

**What to build:** 交易时段自动采集概念与行业的板块主力净流入（约 30 秒一轮），写入本地 SQLite；
页面打开「概念资金分时」时从库里读排行，展示名称、主力净流入、涨跌幅、名次变化，支持点表头排序与
「概念/行业/自选」标签切换；自选板块可增删并跨重启保留。头部显示「最后更新时间 / 交易中」。
页面走 IndexedDB stale-while-revalidate：再次进入立刻有内容，后台静默刷新。
采集失败只记日志，不得影响期权看板与告警链路。

**Blocked by:** 01 — 导航骨架。

**Status:** done

- [x] 采集状态可查（健康接口），页面依据它显示交易中/最后更新时间

### 评审修正（2026-11-04）

- 冷启动竞态：板块库改为 lifespan 里先同步建表，再起采集器；`rank/series/dates` 的 `available_dates`
  也都加了兜底，库未初始化时返回空态而不是 500。
- 手动刷新被缓存吞掉：`usePolling` 在「缓存仍新鲜」分支不再跳过**手动刷新**（有 waiter 时照常请求），
  否则星标增删要等一整个轮询周期才生效。
- 自选并发：改为 `update_watch()` 一次完成读—改—写（加锁 + 唯一临时文件名）。
- 排序改为**点表头**（工单要求），去掉独立的排序按钮行。
