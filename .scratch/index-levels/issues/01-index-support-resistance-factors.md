**Category:** enhancement

**Source:** 用户反馈 #3

## 已有基础

- `indicators.support_resistance()`：用日内枢轴 + 前高前低估算支撑/压力，但只覆盖**当日**区间。
- `market_service` 的指数位置计算：有 MA5 / MA10 / MA20、前低、距 MA20 百分比。
- 策略里已有「指数逼近支撑」告警与护盘加权，但只是**粗粒度**：距 MA20 一个百分比阈值，没把具体点位与多个级别一起算。

## 缺口

用户要的四类位目前缺三类：

| 位 | 现状 |
| --- | --- |
| 阶段高点 / 阶段低点 | 只有日内前高前低，无 20/60 日阶段高低 |
| 百位整数关口 | 完全没有 |
| 5 日均线 | 有 |
| 11 日均线 | 没有（现有 5/10/20） |

## 待定问题（需要拍板）

1. **阶段高低用哪个窗口**？候选：20 日 / 60 日 / 两者都算。建议 20 日（月度节奏）+ 60 日（季度节奏）双档，各有权重。
2. **怎么转成评分**？建议：距最近支撑/压力在 0.3% 内 → ±10；0.3–0.8% → ±5；突破压力且站稳 → 反向加分。需要确认幅度与权重上限，避免和现有国家队/动量权重打架。
3. **整数关口粒度**？上证 3000/3100 这种百位，还是每 50 点？建议百位整数关口，且只在指数距关口 0.5% 内时计入。
4. **只算上证，还是沪深300/创业板也各算一套**？建议先上证（用户明确点名），其余指数复用同一函数但先不进评分。
5. **是否画到图上**？建议第一阶段只进评分与告警文案（「距 20 日低点 0.4%」），图上画线作为后续独立需求，避免一次做太大。
