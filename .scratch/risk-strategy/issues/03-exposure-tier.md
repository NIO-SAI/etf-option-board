# 03 — 敞口档位与组合 Greeks 敞口

**What to build:** 你能声明自己的敞口档位（空仓 / 持有ETF / 持认购 / 持认沽），并为它选一个规模（轻 / 中 / 重 = 总资金 10% / 30% / 60%）。系统据此估出组合 Greeks 敞口，以「标的金额当量（元）」加占总资金比例呈现，并明确标注这是**估算**而不是你的真实敞口。选择在重启后保持。

**Blocked by:** 01 — 设置：总资金与单笔风险%（含测试缝骨架）

**Status:** ready-for-agent

- [ ] 可选择四种敞口档位之一，并选择轻 / 中 / 重三档规模
- [ ] 档位与规模可持久化，服务重启后保持
- [ ] 组合敞口以「标的金额当量（元）」呈现，并同时给出占总资金比例
- [ ] 界面明确标注组合 Greeks 为估算值，不得呈现为真实敞口
- [ ] 持有ETF 档位的 Delta 敞口按持有金额计（恒为 1 元/元）
- [ ] 持认购 / 持认沽档位的单位 Greeks 取当前优选合约
- [ ] 空仓档位敞口为零
- [ ] 优选合约或 Greeks 缺失时相应敞口返回空值并附原因，不抛 500
- [ ] 敞口计算为纯函数，有单元测试覆盖四种档位 × 三种规模、ETF 的 1 元/元、空仓为零
- [ ] 前端可切换档位与规模并通过构建
