# 02 — 板块排行端到端：采集器落库 → 排行接口 → 概念/行业/自选排行页

**What to build:** 交易时段自动采集概念与行业的板块主力净流入（约 30 秒一轮），写入本地 SQLite；
页面打开「概念资金分时」时从库里读排行，展示名称、主力净流入、涨跌幅、名次变化，支持点表头排序与
「概念/行业/自选」标签切换；自选板块可增删并跨重启保留。头部显示「最后更新时间 / 交易中」。
页面走 IndexedDB stale-while-revalidate：再次进入立刻有内容，后台静默刷新。
采集失败只记日志，不得影响期权看板与告警链路。

**Blocked by:** 01 — 导航骨架。

**Status:** ready-for-agent

- [ ] 采集器随服务启动，工作日 09:30–11:30 / 13:00–15:00 每约 30 秒落库；非交易时段不请求
- [ ] 上一轮未完成时跳过下一轮，不堆积并发
- [ ] 库为空/读失败时接口返回 `{error}` 或空列表（不抛 500、不改为实时批量抓取）
- [ ] 排行接口支持 `concept|industry|watch` 与历史日期参数；返回名次变化字段
- [ ] 页面切换标签/排序不产生新的网络请求（本地数据重排）
- [ ] 自选板块增删生效并持久化，服务重启后仍在
- [ ] 数据超过保留窗口自动裁剪（分时 30 交易日、排行 120 交易日）
- [ ] 纯函数单测覆盖：交易时段判定（含午休与边界）、排行解析归一（坏值丢弃）、名次差分、裁剪计划
- [ ] 采集状态可查（健康接口），页面依据它显示交易中/最后更新时间
