# 07 — 策略选择引擎核心

**What to build:** 每次信号不再只给「买认购还是买认沽」，而是给出**策略类型**与理由：买单腿认购 / 买单腿认沽 / 垂直价差 / 观望。看多且 IV 分位高（≥75%）时改推牛市看涨价差以降低买方成本，看空且 IV 分位高时改推熊市看跌价差，震荡且 IV 分位高时明确建议观望；IV 分位低（≤25%）时仍推买单腿；IV 分位缺失时退回中性判断。策略类型与理由同时进入告警文案。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 决策输出包含策略类型：买单腿认购 / 买单腿认沽 / 垂直价差 / 观望，仅此四类
- [ ] 输出包含策略类型对应的理由文案
- [ ] 看多 + IV 分位 ≥75% → 垂直价差（牛市看涨价差）
- [ ] 看空 + IV 分位 ≥75% → 垂直价差（熊市看跌价差）
- [ ] 震荡 + IV 分位 ≥75% → 观望
- [ ] IV 分位 ≤25% + 有明确方向 → 买单腿
- [ ] IV 分位缺失（样本不足）→ 退回中性判断，不给出方向性策略
- [ ] 方向不明确时 → 观望
- [ ] 不产出备兑、保护性认沽、铁鹰、跨式、卖出认沽等被排除的策略
- [ ] 策略类型与理由出现在告警文案中
- [ ] IV 分位阈值沿用 25 / 75，与既有合约打分口径一致
- [ ] 策略判定为纯函数，有单元测试覆盖方向 × 分位的组合、分位缺失、边界值 25 / 75
- [ ] 前端决策卡展示策略类型与理由并通过构建
