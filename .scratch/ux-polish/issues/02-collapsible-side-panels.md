# 左右两侧卡片支持收起 / 展开

> *This was generated by AI during triage.*

**Category:** enhancement
**Status:** ready-for-agent
**Source:** 用户反馈 #6

## 现状

主布局是固定三栏：左侧 340px（期权标的列表 + 大盘指数）、中间自适应（图表/计划）、右侧 360px（候选合约/信号流）。小屏或想专注看主图时，左右两栏无法让位。

## 期望

- 左栏和右栏各自有一个收起/展开控件，互不影响。
- 收起后中间主区自动占满释放的宽度；展开恢复原宽度。
- 状态持久化到本地（localStorage），刷新/切设备同一浏览器保持。
- 提供两种形态，按视口宽度自动选择：
  - 宽屏（≥ lg）：栏位收成窄条（只留竖排图标/竖排标题 + 展开按钮），或完全隐藏留一个悬浮展开按钮。
  - 窄屏（< lg）：沿用现有上下堆叠，收起即折叠该区块，控件位置不跳。
- 有动画但不过度：宽度过渡 `duration-200`，不做位移抖动。

## 验收

- [ ] 左栏可独立收起/展开，右栏可独立收起/展开
- [ ] 收起后主图宽度明显变大，无横向滚动条
- [ ] 刷新页面后收起状态保持
- [ ] 1440px、1024px、390px 三个宽度下均无内容裁切、无重叠
- [ ] 收起状态下仍能看到「展开」入口（不能收进去后找不回来）
- [ ] 键盘可达：控件是 `<button>`，有可读 aria-label（如「收起左侧面板」）
- [ ] 不改动各卡片内部内容与数据逻辑

## 不在范围

- 不做可拖拽调整栏宽
- 不做面板内容自定义排序
